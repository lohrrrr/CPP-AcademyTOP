# Практические работы

Здесь хранятся программы, которые выполняются на занятиях.
Каждая работа занимает отдельную папку `NN-topic`. Заготовку в своей копии
репозитория дополняйте на месте.

| № | Папка | Тема | Что сохранять |
|---|---|---|---|
| 01 | [01-hello-cpp](01-hello-cpp/README.md) | Первая программа и вывод в консоль | `main.cpp`, `report.md`, файлы проекта при использовании |

Первая работа — стартовый пример для знакомства с репозиторием.
Преподаватель дополняет таблицу по мере выдачи заданий.

| Файл работы | Назначение |
|---|---|
| `README.md` | Краткая инструкция преподавателя |
| `tasks.md` | Условия задания |
| `main.cpp` | Код студента, первоначально стартовый файл |
| `report.md` | Ответы и результаты проверок студента |

Порядок сохранения и отправки — в [правилах сдачи](../docs/SUBMIT.md).
