# Практика 01 Первая программа

Стартовая работа для знакомства со средой разработки, консольным выводом
и сохранением кода в GitHub. Выполняйте её в порядке, указанном преподавателем.

1. Настройте среду по [инструкции](../../docs/SETUP.md).
2. Соберите и запустите [`main.cpp`](main.cpp).
3. Выполните задания из [`tasks.md`](tasks.md).
4. Заполните [`report.md`](report.md).
5. Отправьте исходный код, отчёт и файлы проекта при их использовании в свой репозиторий.

Начальная программа выводит `Hello, C++!`.
Команда сборки из корня репозитория при настроенном GCC:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic practice/01-hello-cpp/main.cpp -o hello
```

Запуск: `./hello.exe` в PowerShell или `./hello` в Linux/macOS.
В Visual Studio используйте **Ctrl+F5**.
