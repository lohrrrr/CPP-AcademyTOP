## Первые шаги

1. Создать свой репозиторий кнопкой **Use this template → Create a new repository**.
2. Назвать его `cpp-start` и заполнить карточку выше.
3. Клонировать репозиторий на компьютер и настроить среду по [инструкции](docs/SETUP.md).
4. Открыть [первую практику](practice/01-hello-cpp/README.md), собрать и запустить программу.
5. Сохранить работу коммитом и отправить изменения на GitHub.

Подробный порядок с GitHub Desktop и Git — в [начале работы](docs/START.md).

## Как запустить первую программу

В Visual Studio откройте C++ проект и добавьте существующий файл
[`practice/01-hello-cpp/main.cpp`](practice/01-hello-cpp/main.cpp). Запуск — **Ctrl+F5**.
Пошаговая настройка — в [SETUP.md](docs/SETUP.md).

При настроенном компиляторе GCC из корня репозитория:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic practice/01-hello-cpp/main.cpp -o hello
```

Запуск в PowerShell: `./hello.exe`. В Linux или macOS: `./hello`.
При использовании другого компилятора следуйте инструкции преподавателя.
