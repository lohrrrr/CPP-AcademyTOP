# Обновление материалов курса

Преподаватель добавляет конспекты, условия заданий и стартовые файлы в
`kryovox/cpp-start-template`. В студенческих копиях предусмотрен workflow
**Обновление материалов курса**: ручной запуск и ежедневная проверка
в 06:00 по Москве. GitHub может запускать задания по расписанию с задержкой.

Для получения обновлений исходный шаблон должен быть доступен для чтения
без авторизации. Если преподаватель временно закрыл шаблон, дождитесь открытия доступа.

## Первый запуск и получение новых файлов

1. Откройте **свой** репозиторий на GitHub, вкладку **Actions**.
2. Если GitHub предлагает разрешить запуск workflows в копии, включите их.
3. Выберите **Обновление материалов курса**.
4. Нажмите **Run workflow**, выберите `main` и подтвердите запуск.
5. Дождитесь завершения и откройте сводку: там перечислены добавленные и обновлённые файлы.
6. В GitHub Desktop сохраните и отправьте свои изменения, затем выполните
   **Fetch origin → Pull origin**, чтобы получить обновления на компьютер.

Если кнопка запуска недоступна, убедитесь, что открыли собственную копию
и включили workflow. Если запуск завершается ошибкой доступа, сообщите преподавателю.
В самом репозитории шаблона перенос пропускается.

## Правила переноса

| Файлы | Действие |
|---|---|
| `lectures/`, `materials/`, `docs/`, `assets/` | Обновляются версиями преподавателя |
| `.gitignore`, `.gitattributes`, `.editorconfig` | Обновляются версиями преподавателя |
| Общие `practice/README.md`, `homework/README.md`, `exams/README.md` | Обновляются списки работ |
| `README.md` и `tasks.md` непосредственно в папке выданной работы | Обновляются инструкции и условия |
| Новые стартовые файлы в папках работ | Добавляются, если такого пути у студента ещё нет |
| Существующий код студента, файлы проектов и `report.md` | Сохраняются |
| Личный `README.md` в корне | Сохраняется |
| `.github/` | Сохраняется; изменения workflows преподаватель сообщает отдельно |

Свои заметки и ответы размещайте в `report.md`; инструкции `README.md`
внутри папок выданных работ ведёт преподаватель.
Стартовый код в существующих файлах обновление сохраняет — исправления в таких
заготовках преподаватель сообщает отдельно. Удаление файлов обновлением не выполняется.

После первого обновления удалённая локальная копия стартового файла может появиться снова,
если этот путь по-прежнему есть в шаблоне.

## Если появилась ошибка при отправке

Workflow сохраняет материалы отдельным коммитом `materials: обновление из шаблона курса`.
Если ветка изменилась одновременно с запуском, обновление может завершиться без отправки.
Сохраните свои изменения, получите последние коммиты и запустите workflow повторно.
При конфликте Git обратитесь к преподавателю; сохраните обе версии работы для разбора.
