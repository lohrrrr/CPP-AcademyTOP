# Оформление и сдача работ

## Куда сохранять

| Вид работы | Путь | Пример |
|---|---|---|
| Практика на занятии | `practice/NN-topic/` | `practice/01-hello-cpp/main.cpp` |
| Домашнее задание | `homework/NN-topic/` | `homework/01-variables/main.cpp` |
| Контрольная | `exams/exam-NN/` | `exams/exam-01/main.cpp` |
| Тест | Папка, указанная преподавателем | `exams/quiz-01/report.md` |

Номер и имя папки берите из выданного задания. Примеры путей в этой инструкции
показывают формат; перечень выданных работ находится в README соответствующей папки.

В папке работы хранятся исходный код, файлы проекта при их использовании,
необходимые входные данные и отчёт `report.md` по требованию задания.
Для нескольких самостоятельных программ используйте `task-01/main.cpp`,
`task-02/main.cpp` и отдельные проекты или команды сборки.

## Имена и код

- Папки: две цифры номера, латиница, маленькие буквы и дефис: `02-variables`.
- Главный файл программы: `main.cpp`; заголовки: `.h` или `.hpp`.
- Отчёт: `report.md` рядом с решением.
- Отступы: четыре пробела; переменные называйте по их назначению.
- В отчёте укажите способ запуска и результат проверки программы.

Файлы `.cpp`, `.h`, `.hpp` и необходимые файлы проектов отправляются на GitHub.
Собранные `.exe`, объектные файлы, кэш редактора и папки сборки
исключаются через `.gitignore`. Пароли и токены храните отдельно от репозитория.

## Как назвать коммит

| Изменение | Пример сообщения |
|---|---|
| Начало практики | `practice 01: добавлен вывод приветствия` |
| Исправление | `practice 01: исправлен перенос строки` |
| Домашнее задание | `homework 01: вычисление стоимости покупки` |
| Контрольная | `exam 01: выполнен вариант 2` |
| Оформление портфолио | `profile: добавлена лучшая работа` |

Сообщение должно объяснять изменение. По мере работы делайте небольшие
содержательные коммиты. Для начального этапа курса достаточно ветки `main`.

## Проверка перед отправкой

- [ ] Файлы сохранены в папку выданного задания.
- [ ] Программа собирается и запускается.
- [ ] Проверены примеры из условия; для вычислений добавлены свои входные данные.
- [ ] Я могу объяснить написанный код.
- [ ] Отчёт заполнен, если он требуется.
- [ ] В коммит входят исходники и необходимые файлы проекта.
- [ ] Выполнен **Push origin**; изменения видны на GitHub.

Передавайте преподавателю ссылку на папку конкретной работы.
Статус проверки и оценку сообщает преподаватель.
