# Настройка среды C++

Для выполнения работ нужны редактор, компилятор с поддержкой C++17 и средство
работы с Git. Конкретную среду на занятии уточните у преподавателя.

## Visual Studio на Windows

1. Установите Visual Studio Community с официального сайта Microsoft.
2. В установщике выберите рабочую нагрузку **Разработка классических приложений на C++**
   (**Desktop development with C++**). Если среда уже установлена, откройте
   Visual Studio Installer и нажмите **Изменить**.
3. Создайте **Пустой проект** языка C++ внутри папки соответствующей работы,
   например `practice/01-hello-cpp/HelloCpp/`.
4. В обозревателе решений нажмите правой кнопкой на **Файлы исходного кода**,
   выберите **Добавить → Существующий элемент** и укажите файл
   `practice/01-hello-cpp/main.cpp` из репозитория.
5. В свойствах проекта, **C/C++ → Язык → Стандарт языка C++**, выберите C++17
   или согласованный с преподавателем более новый стандарт.
6. Нажмите **Ctrl+F5** для сборки и запуска без отладчика.

Файлы проекта `.sln`, `.slnx`, `.vcxproj` и `.vcxproj.filters` можно сохранять
в репозитории. Служебные папки и результаты сборки исключены через `.gitignore`.
Для каждой отдельной программы создавайте свой проект.

## VS Code с GCC

Этот вариант подходит, если GCC уже установлен и доступен в терминале.
Расширение **C/C++** в VS Code добавляет поддержку языка; компилятор
устанавливается отдельно. При первой настройке следуйте инструкции преподавателя.

Проверьте доступность компилятора:

```bash
g++ --version
```

Откройте в VS Code корень своего репозитория. В терминале соберите первую программу:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic practice/01-hello-cpp/main.cpp -o hello
```

В PowerShell запустите:

```powershell
./hello.exe
```

В Linux или macOS при доступном GCC:

```bash
./hello
```

Ожидаемый вывод стартового файла:

```text
Hello, C++!
```

## Частые затруднения

| Ситуация | Что проверить |
|---|---|
| `g++` не найден | Установку компилятора, PATH и перезапуск терминала |
| Ошибка о нескольких `main` | В проект подключена одна программа со своей функцией `main` |
| Ошибка о пропущенном символе | Строку ошибки и предыдущую строку: кавычки, скобки, `;` |
| Запускается старая версия | Изменения сохранены, сборка завершилась успешно, запускается нужный файл |
| Нечитаемая кириллица | На первых работах используйте латиницу в выводе; UTF-8 консоли настройте с преподавателем |

Сначала добейтесь запуска стартового файла, затем изменяйте его по заданию.
