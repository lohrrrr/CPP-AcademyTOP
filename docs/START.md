# Начало работы

## Создайте личный репозиторий

1. Войдите в свой аккаунт GitHub и откройте [шаблон курса](https://github.com/kryovox/cpp-start-template).
2. Нажмите **Use this template → Create a new repository**.
3. В поле **Owner** выберите свой аккаунт. Имя репозитория — `cpp-start`.
4. Выберите видимость по договорённости с преподавателем. Для закрытого репозитория
   потребуется предоставить преподавателю доступ.
5. Оставьте копирование всех веток выключенным, если такой переключатель показан.
6. Нажмите **Create repository**.
7. В своём `README.md` заполните имя, группу и среду разработки.

В дальнейшем работайте в репозитории своего аккаунта.

## Скопируйте файлы на компьютер

Установите GitHub Desktop с официального сайта, если он ещё не установлен,
и войдите в тот же аккаунт GitHub.

1. В GitHub Desktop выберите **File → Clone repository**.
2. Найдите свой `cpp-start`, выберите папку на компьютере и нажмите **Clone**.
3. Откройте локальную папку в редакторе.
4. Настройте C++ по [SETUP.md](SETUP.md).

Вариант для установленного Git: замените `YOUR_LOGIN` своим логином и выполните:

```bash
git clone https://github.com/YOUR_LOGIN/cpp-start.git
cd cpp-start
```

## Сохраните первое изменение

После заполнения карточки студента:

1. Откройте GitHub Desktop, вкладку **Changes**.
2. Проверьте список изменённых файлов.
3. В поле **Summary** введите `profile: заполнена карточка студента`.
4. Нажмите **Commit to main**, затем **Push origin**.
5. Откройте свой репозиторий на GitHub и убедитесь, что карточка обновилась.

Коммит сохраняет изменение в истории на компьютере. **Push origin** отправляет
его на GitHub. Для получения изменений используйте **Fetch origin**, а при
появлении новых коммитов — **Pull origin**.

## Обычный порядок работы

1. Перед занятием сохраните и отправьте прошлые изменения, затем получите новые через **Pull origin**.
2. Выполните задание в указанной папке.
3. Соберите программу и проверьте результат.
4. Заполните `report.md`, если отчёт указан в задании.
5. Сделайте содержательный коммит и нажмите **Push origin**.
6. Откройте работу на GitHub и передайте преподавателю ссылку на её папку.

Для получения новых материалов курса прочитайте [UPDATES.md](UPDATES.md).
