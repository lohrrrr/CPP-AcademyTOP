# Материалы курса

Здесь преподаватель размещает дополнительные примеры, входные данные
и файлы для заданий. Сейчас для старта достаточно файлов первой практики.

У каждого нового набора материалов будет своя папка и пояснение к использованию.
Эта папка обновляется из шаблона; свои решения сохраняйте в `practice/`,
`homework/` и `exams/`.
