# Подготовка к работе

Это стартовая организационная работа: личная копия репозитория, запуск
программы и первая отправка изменений. Выполняйте её по указанию преподавателя;
среду можно настроить на занятии.

1. Создайте свой `cpp-start` из шаблона и клонируйте его на компьютер.
2. Заполните карточку студента в корневом `README.md`.
3. Настройте среду и запустите стартовый файл из `practice/01-hello-cpp/`.
4. Заполните [`report.md`](report.md), укажите среду и фактический вывод.
5. Сделайте коммит `homework 00: подготовлен репозиторий и проверен запуск`.
6. Отправьте изменения и передайте преподавателю ссылку на свой репозиторий.

Инструкции: [начало работы](../../docs/START.md), [настройка среды](../../docs/SETUP.md).
